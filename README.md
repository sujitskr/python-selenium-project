# Python Selenium Automation Project

## 📌 Overview
This project is an **educational Python Selenium automation project** focused on understanding
how OTP-based login systems work and how **security mechanisms such as rate-limiting,
timeouts, and verification flows** are implemented.

⚠️ This project is strictly for **learning, testing, and security awareness purposes**
using **demo or test websites only**.

---

## 🧠 Purpose
- Learn Selenium automation
- Understand OTP verification flows
- Study how applications prevent abuse
- Practice handling popups, waits, and dynamic elements
- Improve automation logic & exception handling

---

## 🛠️ Tech Stack
- **Python**
- **Selenium**
- **WebDriverWait & Expected Conditions**
- **OS module**
- **Requests (optional testing)**
- **BeautifulSoup (HTML parsing for demo pages)**

---

## 🧪 Tested On
- Public demo websites
- Automation practice platforms (e.g. test login pages)
- Local or self-hosted test environments

❌ Not tested on real user accounts or production systems.
